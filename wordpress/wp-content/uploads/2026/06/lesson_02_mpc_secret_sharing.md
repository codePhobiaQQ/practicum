# Урок 2: Многостороннее вычисление (MPC) — Shamir Secret Sharing и базовые протоколы

## Введение

Многостороннее вычисление (Multi-Party Computation, MPC) позволяет нескольким участникам **совместно вычислить функцию от их секретных входов**, при этом каждый узнаёт только результат, но не входные данные других участников.

**Пример задачи:** Три компании хотят узнать, у кого наибольшая выручка, не раскрывая конкретные цифры друг другу.

---

## 1. Схема разделения секрета Шамира (Shamir Secret Sharing)

### Идея

Секрет `s` делится на `n` долей (`shares`) так, что:
- Любые `t` или более долей позволяют восстановить `s`.
- Любые `t-1` или менее долей не дают никакой информации о `s`.

Это называется **(t, n)-пороговая схема**.

### Математическая основа: полиномиальная интерполяция

```
Выбрать случайный полином степени t-1:
  f(x) = s + a₁x + a₂x² + ... + a_{t-1}x^{t-1}  (mod p)

Доли: sᵢ = f(i) для i = 1, ..., n

Восстановление через интерполяцию Лагранжа:
  s = f(0) = Σᵢ sᵢ · ∏_{j≠i} (0-j)/(i-j)  (mod p)
```

### Реализация

```python
import secrets
from functools import reduce

PRIME = 2**127 - 1  # поле F_p

def poly_eval(coeffs: list[int], x: int) -> int:
    """Вычислить полином с коэффициентами coeffs в точке x (mod PRIME)"""
    result = 0
    for coeff in reversed(coeffs):
        result = (result * x + coeff) % PRIME
    return result

def make_shares(secret: int, t: int, n: int) -> list[tuple[int, int]]:
    """Разделить secret на n долей с порогом t"""
    assert t <= n, "Порог не может превышать число долей"
    # Случайные коэффициенты (кроме свободного члена = secret)
    coeffs = [secret] + [secrets.randbelow(PRIME) for _ in range(t - 1)]
    return [(i, poly_eval(coeffs, i)) for i in range(1, n + 1)]

def lagrange_interpolate(shares: list[tuple[int, int]]) -> int:
    """Восстановить секрет из долей через интерполяцию Лагранжа"""
    def mod_inv(a: int) -> int:
        return pow(a, PRIME - 2, PRIME)  # теорема Ферма

    secret = 0
    xs = [s[0] for s in shares]
    ys = [s[1] for s in shares]

    for i, (xi, yi) in enumerate(zip(xs, ys)):
        num = den = 1
        for j, xj in enumerate(xs):
            if i != j:
                num = (num * (0 - xj)) % PRIME
                den = (den * (xi - xj)) % PRIME
        secret = (secret + yi * num * mod_inv(den)) % PRIME

    return secret

# Демонстрация
secret = 42_000_000
shares = make_shares(secret, t=3, n=5)
print(f"Доли: {shares}")

# Восстановление из любых 3 долей
recovered = lagrange_interpolate(shares[:3])
print(f"Восстановлено: {recovered}")  # 42000000
```

## 2. Умножение долей: проблема и решение

Сложение долей линейно — тривиально:

```python
def add_shares(s1: list[tuple], s2: list[tuple]) -> list[tuple]:
    return [(x1, (y1 + y2) % PRIME)
            for (x1, y1), (_, y2) in zip(s1, s2)]
```

Умножение сложнее: `f(x) · g(x)` имеет степень `2(t-1)`, нужен **протокол перерандомизации (degree reduction)**.

```
Протокол умножения (упрощённо):
1. Каждый участник Pᵢ вычисляет cᵢ = aᵢ · bᵢ (локально)
2. Pᵢ разделяет cᵢ как новый секрет: [cᵢ]
3. Участники обмениваются и применяют коэффициенты Лагранжа
4. Итог: [a · b] степени t-1
```

## 3. Протокол GMW (Goldreich-Micali-Wigderson)

GMW — классический протокол MPC для булевых схем:

```
Вход: каждый участник Pᵢ имеет бит xᵢ
Цель: вычислить f(x₁, ..., xₙ) без раскрытия входов

Шаг 1 (Secret Sharing):
  Каждый Pᵢ делит свой бит на XOR-доли:
  xᵢ = xᵢ₁ ⊕ xᵢ₂ ⊕ ... ⊕ xᵢₙ
  Отправляет долю xᵢⱼ участнику Pⱼ.

Шаг 2 (Gate Evaluation):
  XOR-ворота: тривиальны (XOR долей локально)
  AND-ворота: требуют Oblivious Transfer (OT)

Шаг 3 (Output):
  Участники публикуют доли выхода и восстанавливают результат.
```

## 4. Oblivious Transfer (OT) — строительный блок MPC

OT позволяет отправителю передать одно из двух сообщений по выбору получателя, не узнавая, какое именно было выбрано.

```
Протокол 1-из-2 OT:
  Отправитель: m₀, m₁
  Получатель: бит выбора b

1. Получатель генерирует ключи: pk_b (для которого знает sk),
   pk_{1-b} (случайный, sk неизвестен)
2. Отправитель: enc(pk₀, m₀), enc(pk₁, m₁)
3. Получатель: dec(pk_b, enc(pk_b, m_b)) = m_b
   Не может расшифровать m_{1-b}

Результат: получатель узнаёт только m_b
```

## 5. Применения MPC в реальном мире

| Применение | Участники | Что вычисляется |
|---|---|---|
| **Аукцион без раскрытия** | Участники торгов | Максимальная ставка |
| **Совместный ML** | Банки | Модель fraud detection |
| **Пороговые подписи** | Валидаторы | Подпись транзакции |
| **Private Set Intersection** | Компании | Пересечение клиентских баз |
| **Медицинские исследования** | Больницы | Статистика по данным пациентов |

### Пример: Private Set Intersection (PSI)

```python
# Упрощённая версия PSI через хеширование (не криптографически стойкая!)
def naive_psi(set_a: set, set_b: set) -> set:
    """
    Реальный PSI использует OT или гомоморфное шифрование.
    Это только иллюстрация протокола.
    """
    import hashlib
    hash_a = {hashlib.sha256(x.encode()).hexdigest() for x in set_a}
    hash_b = {hashlib.sha256(x.encode()).hexdigest() for x in set_b}
    common_hashes = hash_a & hash_b
    return {x for x in set_a if hashlib.sha256(x.encode()).hexdigest() in common_hashes}
```
