# Урок 1: Доказательства с нулевым разглашением (Zero-Knowledge Proofs)

## Введение

Доказательство с нулевым разглашением (ZKP) — это криптографический протокол, в котором **доказывающий (prover)** убеждает **верификатора (verifier)** в истинности некоторого утверждения, не раскрывая никакой дополнительной информации, кроме самого факта истинности.

---

## 1. Интуиция: пещера Али-Бабы

Классический пример Жан-Жака Киффера:

```
        Вход
          |
   ───────┤├───────
   A      │      B
          │
        (Дверь с кодом)
```

- Пещера имеет форму кольца с одним входом и дверью, делящей путь на два прохода A и B.
- Алиса знает код от двери. Она хочет доказать это Бобу, не раскрывая код.
- **Протокол:** Алиса заходит и выбирает проход (A или B). Боб кричит, из какого прохода должна выйти Алиса. Если Алиса знает код — она всегда выходит правильно.
- После `n` повторений вероятность обмана `= (1/2)^n`.

---

## 2. Формальное определение

ZKP должно удовлетворять трём свойствам:

| Свойство | Определение |
|---|---|
| **Полнота (Completeness)** | Если утверждение истинно, честный prover убедит верификатора |
| **Корректность (Soundness)** | Нечестный prover не сможет убедить верификатора в ложном утверждении |
| **Нулевое разглашение (ZK)** | Верификатор не узнаёт ничего, кроме истинности утверждения |

### Формально (интерактивный ZKP)

```
Prover P знает: секрет w (witness)
Утверждение: "я знаю w такой, что f(w) = y"

Раунд i:
  1. P → V : commitment c_i
  2. V → P : challenge e_i  (случайный)
  3. P → V : response r_i

V проверяет: verify(y, c_i, e_i, r_i) = true
```

---

## 3. Схема Шнорра — ZKP знания дискретного логарифма

**Задача:** Prover знает `x` такой, что `Y = g^x mod p`.

```
Параметры: группа G, генератор g, публичный ключ Y = g^x

1. P: выбирает случайное r; вычисляет R = g^r
   P → V: R

2. V: выбирает случайный challenge e ∈ {0,...,2^128}
   V → P: e

3. P: вычисляет s = r + x·e (mod q)
   P → V: s

4. V: проверяет g^s = R · Y^e (mod p)
```

**Почему это ZK?** Симулятор может создать валидный transcript без знания `x`:
- Выбрать случайные `s` и `e`
- Вычислить `R = g^s · Y^(-e)`
- Transcript `(R, e, s)` статистически неотличим от реального.

### Реализация на Python

```python
import secrets
from dataclasses import dataclass

# Простые параметры (в продакшене использовать стандартные группы!)
P = 2**127 - 1  # простое число (Mersenne prime)
Q = (P - 1) // 2
G = 4  # генератор подгруппы порядка Q

@dataclass
class SchnorrProof:
    R: int
    s: int

def schnorr_prove(x: int, e: int) -> SchnorrProof:
    """Создать доказательство знания x, где Y = G^x mod P"""
    r = secrets.randbelow(Q)
    R = pow(G, r, P)
    s = (r + x * e) % Q
    return SchnorrProof(R=R, s=s)

def schnorr_verify(Y: int, proof: SchnorrProof, e: int) -> bool:
    """Проверить доказательство"""
    lhs = pow(G, proof.s, P)
    rhs = (proof.R * pow(Y, e, P)) % P
    return lhs == rhs

# Пример использования
x = secrets.randbelow(Q)         # секретный ключ
Y = pow(G, x, P)                  # публичный ключ

e = secrets.randbelow(2**128)     # challenge от верификатора
proof = schnorr_prove(x, e)
print(schnorr_verify(Y, proof, e))  # True
```

## 4. Non-Interactive ZKP (NIZK) и Fiat-Shamir

Интерактивный ZKP требует нескольких раундов. **Трансформация Фиата-Шамира** делает его неинтерактивным:

```python
import hashlib

def fiat_shamir_challenge(R: int, Y: int, context: bytes = b"") -> int:
    """Детерминированный challenge через хеш"""
    h = hashlib.sha256()
    h.update(R.to_bytes(32, 'big'))
    h.update(Y.to_bytes(32, 'big'))
    h.update(context)
    return int.from_bytes(h.digest(), 'big') % Q

def schnorr_sign(x: int, message: bytes) -> SchnorrProof:
    """Подпись Шнорра = NIZK через Fiat-Shamir"""
    Y = pow(G, x, P)
    r = secrets.randbelow(Q)
    R = pow(G, r, P)
    e = fiat_shamir_challenge(R, Y, message)
    s = (r + x * e) % Q
    return SchnorrProof(R=R, s=s)
```

## 5. Современные ZKP-системы

| Система | Тип | Размер доказательства | Применение |
|---|---|---|---|
| **Groth16** | zk-SNARK | ~200 байт | Zcash, zkRollups |
