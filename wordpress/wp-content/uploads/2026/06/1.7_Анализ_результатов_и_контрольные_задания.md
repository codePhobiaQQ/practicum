# Анализ результатов и контрольные задания

## Просмотр и анализ корневого сертификата

1. Откройте директорию `C:\Windows\System32\CertSrv\CertEnroll`.
2. Найдите файл с расширением `.crt` (например, `Study.su_SERVER-CA-CA.crt`).
3. Дважды щёлкните по файлу для открытия, перейдите на вкладку **"Подробно"**.

> [!task] Задание: Анализ свойств корневого сертификата
> Заполните таблицу на основе данных открытого корневого сертификата:

| Параметр | Значение |
| --- | --- |
| Издатель сертификата | 1. _______ |
| Владелец сертификата | 2. _______ |
| Срок действия в годах | 3. _______ |
| Длина открытого ключа | 4. _______ бит |
| Серийный номер (первые 4 байта в шестнадцатеричном формате) | 5. _______ |
| Алгоритм подписи и хеширования | 6. _______ |

## Анализ списков отзыва сертификатов

1. В той же директории `CertEnroll` найдите файл с расширением `.crl`.
2. Откройте файл с помощью утилиты командной строки `certutil -dump имя_файла.crl` или через оснастку **"Сертификаты"**.

## Проверка состояния инфраструктуры через оснастку pkiview.msc

1. Запустите приложение `pkiview.msc` через диалоговое окно **"Выполнить"**.
2. Раскройте узел **"Корпоративная инфраструктура открытых ключей"** -> `SERVER-CA.study.su`.
3. Проверьте статус следующих компонентов:
   - Сертификат центра сертификации: должен отображаться зелёным индикатором.
   - Список отзыва сертификатов: статус **"ОК"**, дата последнего обновления актуальна.
   - Дельта-список отзыва: статус **"ОК"** при включённой публикации.
