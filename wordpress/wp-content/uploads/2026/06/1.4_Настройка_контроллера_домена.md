# Настройка контроллера домена

## Настройка компьютера SERVER-AD в роли контроллера домена

Выполнение данной части лабораторной работы осуществляется на виртуальной машине `SERVER-AD`.

> [!attention] Предварительные требования
> - Убедитесь, что на виртуальной машине установлен статический IP-адрес (192.168.0.1).
> - В настройках сетевого адаптера укажите предпочитаемый DNS-сервер: 127.0.0.1.
> - Создайте контрольную точку (снэпшот) виртуальной машины перед началом настройки.

### Пошаговая инструкция

1. В секции **"Локальный сервер"** окна **"Диспетчер серверов"** щёлкните по ссылке **"Имя компьютера"**.

   > [!note] Примечание
   > Если окно "Диспетчер серверов" не было открыто ранее, откройте его с помощью соответствующего значка на панели задач операционной системы Windows.

2. В диалоговом окне **"Свойства системы"** на вкладке **"Имя компьютера"** нажмите кнопку **"Изменить"**. В появившемся предупреждении нажмите кнопку **"ОК"**.

3. Присвойте компьютеру имя `SERVER-AD`, нажмите кнопку **"ОК"**.

4. Нажмите кнопку **"ОК"** в диалоговом окне **"Изменение имени компьютера или домена"**.

5. Последовательно нажмите кнопки **"Закрыть"** и **"Перезагрузить сейчас"**.

6. После перезапуска сервера в окне **"Диспетчера серверов"** выберите пункт меню **"Управление"** -> **"Добавить роли и компоненты"**.

7. На странице **"Перед началом работы"** диалогового окна **"Мастер добавления ролей и компонентов"** нажмите кнопку **"Далее"**.

   - 7.1. На странице **"Выбор типа установки"** выберите **"Установка ролей или компонентов"** и нажмите кнопку **"Далее"**.
   - 7.2. На странице **"Выбор целевого сервера"** оставьте опцию **"Выберите сервер из пула адресов"** и `SERVER-AD (192.168.0.1)`. Нажмите **"Далее"**.

8. Установите флажок **"Доменные службы Active Directory"** и нажмите кнопку **"Добавить компоненты"**, затем три раза нажмите кнопку **"Далее"**.

9. В диалоговом окне **"Подтверждение установки компонентов"** установите флажок **"Автоматический перезапуск конечного сервера, если требуется"**, нажмите кнопку **"Да, Установить"**.

10. Дождитесь завершения установки. В диалоговом окне **"Ход установки"** нажмите кнопку **"Закрыть"**.

11. В окне **"Диспетчер серверов"** в секции **"Панель мониторинга"** в правом верхнем углу нажмите на значок уведомления и выберите **"Повысить роль данного сервера до уровня контроллера домена"**.

12. На странице **"Мастер настройки доменных служб Active Directory"** выберите **"Добавить новый лес"**, в поле **"Имя корневого домена"** введите имя `Study.su` и нажмите **"Далее"**.

13. В окне **"Параметры домена"** выберите в списках **"Режим работы леса"** и **"Режим работы домена"** пункты **"Windows Server 2012 R2"**.

14. Подтвердите установку **"DNS-сервера"** в качестве дополнительного свойства контроллера домена.

15. Введите пароль в поле **"Пароль для режима восстановления служб каталогов"** (например, `QWErt123`) и подтвердите его, нажмите **"Далее"**.

16. В следующем окне **"Параметры DNS"** нажмите **"Далее"**.

17. Проверьте имя доменной сети в формате NETBIOS, в данном случае `STUDY`, нажмите **"Далее"**.

18. Согласитесь с настройками папок по умолчанию, нажав **"Далее"**.

19. Проверьте все настроенные параметры:
    - Сделать данный сервер первым контроллером домена Active Directory в новом лесу.
    - Имя нового домена: `Study.su` (это имя является также именем нового леса).
    - Имя домена в формате NETBIOS: `STUDY`.
    - Режим работы леса: `Windows Server 2012 R2`.
    - Режим работы домена: `Windows Server 2012 R2`.
    - Глобальный каталог: Да.
    - DNS-сервер: Да.
    - Создать делегирование DNS: Нет.
    - Папка базы данных: `C:\Windows\NTDS`.
    - Папка файлов журнала: `C:\Windows\NTDS`.
    - Папка SYSVOL: `C:\Windows\SYSVOL`.
    - Служба DNS-сервера будет настроена на этом компьютере.
    - Данный DNS-сервер будет настроен в качестве предпочитаемого DNS-сервера для этого компьютера.
    - Пароль администратора нового домена будет таким же, как и пароль локального администратора этого компьютера.

20. При соответствии всех настроек последовательно нажмите **"Далее"** и **"Установить"**.

21. Мастер установки доменных служб приступит к настройке службы Active Directory. По завершении настройки компьютер будет автоматически перезагружен.

22. После перезагрузки осуществите вход под учётной записью **"Администратор"**. Пароль администратора нового домена будет таким же, как и пароль локального администратора этого компьютера.

23. При первом входе в домен потребуется сменить пароль. В качестве нового пароля выберите `QWErt1234`.

> [!summary] Простыми словами
> Повышение роли сервера до контроллера домена превращает обычный Windows Server в центр управления всей сетью. Он начинает хранить базу пользователей, управлять политиками безопасности и обслуживать DNS. Важно не устанавливать эту роль на серверах общего назначения без необходимости, так как отказ контроллера домена останавливает аутентификацию всех компьютеров в сети.

## Мини-тест по разделу 1.4

1. Какой пароль требуется ввести при первом входе в домен после повышения роли?
   - [ ] Тот же, что использовался локально
   - [x] Новый пароль, соответствующий политике сложности домена
   - [ ] Пароль не требуется

2. Какая служба автоматически устанавливается вместе с ролями доменных служб Active Directory?
   - [x] DNS-сервер
   - [ ] DHCP-сервер
   - [ ] Веб-сервер (IIS)

3. Где хранится база данных Active Directory по умолчанию?
   - [ ] `C:\Program Files\Windows NT`
   - [x] `C:\Windows\NTDS`
   - [ ] `C:\Windows\System32\Config`
