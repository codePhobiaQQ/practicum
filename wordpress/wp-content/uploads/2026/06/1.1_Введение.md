# Лабораторная работа №1.0: Разворачивание одноуровневой ИОК на основе Windows Server 2012

## Аннотация

В данной лабораторной работе выполняется развёртывание одноуровневой инфраструктуры открытых ключей (ИОК) на базе операционной системы Windows Server 2012. В процессе выполнения работы изучается распределение ролей между контроллером домена (Active Directory), центром сертификации (Certification Authority) и клиентскими рабочими станциями. Рассматриваются форматы цифровых сертификатов стандарта X.509, механизмы отзыва сертификатов (CRL) и принципы построения цепочки доверия в корпоративной среде.

> [!summary] Кратко о сути работы
> Вы создадите собственный центр выдачи цифровых сертификатов внутри учебного домена. Это позволит безопасно аутентифицировать пользователей, шифровать трафик и подписывать документы без предварительной передачи секретных ключей.

## Цели лабораторной работы

- Сформировать системное понимание архитектуры и принципов функционирования инфраструктуры открытых ключей в корпоративной среде.
- Приобрести практические навыки развёртывания и базовой настройки служб сертификации Active Directory (AD CS).
- Изучить механизмы управления жизненным циклом цифровых сертификатов и обеспечения доверия в сети.

## Требования к результатам освоения

### Знать

- Архитектуру и компоненты инфраструктуры открытых ключей: центр сертификации, регистрационный центр, хранилище сертификатов, политику сертификации.
- Стандарт X.509 версии 3, структуру сертификата в нотации ASN.1 и механизмы кодирования DER.
- Принципы работы списков отзыва сертификатов, протоколов OCSP и расширений сертификатов: Key Usage, Basic Constraints, CRL Distribution Points, Authority Information Access.
- Требования информационной безопасности при размещении ролей служб домена Active Directory и служб сертификации.

### Уметь

- Разворачивать одноуровневую инфраструктуру открытых ключей на базе операционной системы Windows Server.
- Настраивать политику центра сертификации через конфигурационный файл CAPolicy.inf.
- Управлять учётными записями пользователей и делегировать права администратора предприятия.
- Анализировать свойства цифровых сертификатов, проверять цепочку доверия и статус отзыва.
- Диагностировать и устранять типовые ошибки публикации списков отзыва и точек доступа к информации об издателе.

### Владеть

- Методикой проектирования базовой инфраструктуры открытых ключей для организаций малого и среднего масштаба.
- Инструментами администрирования служб сертификации Active Directory: оснастки certsrv.msc, pkiview.msc, утилита certutil.
- Практиками безопасного управления закрытыми ключами корневого центра сертификации.
- Навыками работы с нормативной базой: ГОСТ Р 34.10, RFC 5280, рекомендации ФСТЭК России.
