Веб-разработка для начинающих

Тестовый курс · ~4 месяца · бесплатная вводная часть

О курсе

Это демонстрационный HTML для проверки вёрстки и импорта в WordPress (поле «Описание» или контент страницы). Вы освоите основы HTML, CSS и JavaScript и сверстаете первую лендинг-страницу.

Курс подойдёт тем, кто только начинает путь в IT и хочет понять, нравится ли ему фронтенд до оплаты полной программы.

Программа (фрагмент)

  1. Модуль 1. Как устроен браузер и интернет-страница.
  2. Модуль 2. Семантическая вёрстка и доступность.
  3. Модуль 3. Стили: Flexbox, адаптив, переменные.
  4. Модуль 4. Базовый JavaScript: переменные, функции, DOM.

Чему научитесь

  • Писать валидный HTML5 и подключать стили.
  • Верстать блоки по макету и адаптировать под мобильные экраны.
  • Добавлять простую интерактивность на страницу.
